## 🔧 参数调优指南

### **学习率策略**
```python
# Non-IID场景
--lr 0.001              # 稳定学习率
--optimizer adamw       # 适合复杂模型

# IID场景  
--lr 0.002              # 可以稍高
--optimizer adamw       # 或sgd都可以
```

### **正则化配置**
```python
# 轻量级模型
--dropout_rate 0.3      # 适中dropout
--label_smoothing 0.1   # 标签平滑

# Ultra模型
--dropout_rate 0.4      # 更高dropout
--label_smoothing 0.15  # 更多平滑
```

### **联邦学习参数**
```python
# Non-IID优化
--local_ep 5            # 减少本地轮数
--frac 0.5              # 高参与率
--alpha 0.3             # 中等Non-IID

# IID场景
--local_ep 8            # 可以更多轮数
--frac 0.5              # 保持高参与率
--alpha 0.2             # 较低Non-IID
```
