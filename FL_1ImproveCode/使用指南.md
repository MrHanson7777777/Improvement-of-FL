# 联邦学习模型架构改进效果验证 - 代码使用指南

## 📋 项目概述

本项目实现了联邦学习框架，支持多种深度学习模型架构，专门针对图像分类任务（MNIST、Fashion-MNIST、CIFAR-10、CIFAR-100）进行优化。项目包含三个主要版本：原始版本、改进版本和最终优化版本，用于验证模型架构改进和优化策略的效果。

## 📊 支持的数据集和模型

### 数据集

- **MNIST**: 手写数字识别（28×28灰度图像）
- **Fashion-MNIST**: 时尚物品分类（28×28灰度图像）
- **CIFAR-10**: 自然图像分类（32×32彩色图像，10类）
- **CIFAR-100**: 自然图像分类（32×32彩色图像，100类）

### 模型架构

| 模型名称        | 命令行参数            | 描述                      | 适用数据集          | 目标精度 |
| --------------- | --------------------- | ------------------------- | ------------------- | -------- |
| 基础CNN         | `cnn`               | 传统卷积神经网络          | 所有                | 70-80%   |
| 增强CNN         | `enhanced_cnn`      | 基于EfficientNet的增强CNN | CIFAR               | 80-85%   |
| ResNet-50       | `resnet50`          | 深度残差网络              | CIFAR               | 82-87%   |
| Wide ResNet     | `wide_resnet`       | 宽度增强的ResNet          | CIFAR               | 85-90%   |
| 超高性能CNN     | `ultra_cnn`         | 专为CIFAR优化的CNN        | CIFAR               | 85%+     |
| 优化Wide ResNet | `ultra_wide_resnet` | 高度优化的Wide ResNet     | CIFAR               | 87%+     |
| 终极CIFAR模型   | `cifar_ultra`       | 集成多种优化技术          | CIFAR               | 87%+     |
| MLP             | `mlp`               | 多层感知机                | MNIST/Fashion-MNIST | 85%+     |

## ⚙️ 关键参数说明

### 基础参数

- `--dataset`: 数据集选择 (`mnist`, `fmnist`, `cifar`, `cifar100`)
- `--model`: 模型架构选择（见上表）
- `--epochs`: 全局训练轮数
- `--num_users`: 联邦学习客户端总数
- `--frac`: 每轮参与训练的客户端比例
- `--local_ep`: 本地训练轮数
- `--local_bs`: 本地批次大小
- `--lr`: 学习率
- `--gpu`: GPU设备ID（-1表示使用CPU）
- `--seed`: 随机种子

### 优化器参数

- `--optimizer`: 优化器类型 (`sgd`, `adam`, `adamw`)
- `--momentum`: SGD动量参数
- `--weight_decay`: 权重衰减（L2正则化）

### 学习率调度

- `--use_scheduler`: 启用学习率调度
- `--scheduler`: 调度器类型 (`step`, `cosine`, `exponential`)
- `--lr_decay`: 学习率衰减因子
- `--lr_decay_step`: 学习率衰减步长
- `--warmup_epochs`: 预热轮数

### 数据增强

- `--use_mixup`: 启用MixUp数据增强
- `--use_cutmix`: 启用CutMix数据增强
- `--mixup_alpha`: MixUp混合参数
- `--cutmix_alpha`: CutMix混合参数

### 正则化

- `--use_label_smoothing`: 启用标签平滑
- `--label_smoothing`: 标签平滑因子
- `--dropout`: Dropout比例

### 训练控制

- `--stopping_rounds`: 早停轮数
- `--verbose`: 详细输出级别
- `--iid`: 是否使用IID数据分布
- `--unequal`: 是否使用不等量数据分配

## 🔧 故障排除

### 常见问题

1. **GPU内存不足**

   - 减少 `--local_bs` 批次大小
   - 使用 `--gpu -1` 切换到CPU训练
2. **训练收敛慢**

   - 增加 `--warmup_epochs` 预热轮数
   - 调整学习率 `--lr`
   - 启用数据增强 `--use_mixup --use_cutmix`
3. **精度不理想**

   - 增加训练轮数 `--epochs`
   - 提高客户端参与比例 `--frac`
   - 使用更复杂的模型架构
4. **过拟合问题**

   - 启用正则化 `--weight_decay`
   - 使用标签平滑 `--use_label_smoothing`
   - 减少本地训练轮数 `--local_ep`

### 性能优化建议

1. **达到85%+ CIFAR-10精度的建议配置**：

   - 使用 `cifar_ultra` 或 `ultra_wide_resnet` 模型
   - 设置较大的客户端参与比例（`--frac 0.3`）
   - 启用所有数据增强策略
   - 使用余弦退火学习率调度
   - 增加训练轮数到300+
2. **加速训练**：

   - 使用GPU训练
   - 增加批次大小
   - 减少客户端数量但提高参与比例
   - 使用较大的初始学习率配合warmup

## 🎯 最佳实践

1. **模型选择**：对于CIFAR-10追求高精度，推荐使用 `cifar_ultra` 模型
2. **参数调优**：先使用较少轮数快速测试，确定合适参数后再进行完整训练
3. **数据增强**：对于小数据集，数据增强效果显著，建议全部启用
4. **学习率调度**：余弦退火调度通常效果最好
5. **早停机制**：设置合适的早停轮数避免过拟合
6. **随机种子**：使用固定种子确保实验可重复
